# 平台架构与接口

新版采用模块化单体。FastAPI 提供同步业务事务和读取接口，Celery 处理采集、导入、评价、训练、预测、插补和导出。调度器独立运行，前端通过任务轮询查看进度。Nginx 同源提供 React 和 `/api/v2`。

## 模块边界

| 模块 | 责任 |
| --- | --- |
| auth | Argon2 口令、会话 Cookie、CSRF、吊销、失败计数及拒绝审计 |
| monitoring 和 collection | 城市站点、原始文件修订、时序与质量查询 |
| evaluation 和 seed | 标准有效期、完整性、站点日评价及独立 AQI |
| jobs tasks scheduler | 任务事务、发件箱、队列、心跳、恢复和计划 |
| datasets forecasting imputation ml | 数据快照、隔离训练、原尺度评估、制品与推理 |
| enforcement | 企业资料、线索认领、任务归属、整改状态机、附件 |
| admin notifications | 标准法规和模型维护、站内及可选外部通知 |
| storage exports backup | 私有内容寻址文件、受控导出、备份核验 |

## API 契约

分页参数为 `page_number` 和 `page_size`，返回 `items,total,page,page_size,request_id`。监测时间范围为北京自然日 `start,end`，观测瞬时值存 UTC。分页采用稳定主键作为同值排序的次序。错误返回稳定 `code,message,details,request_id`，不回传 SQL、服务器路径或秘密。

`POST /jobs` 和 `POST /imports` 返回 202 与 `job_id`；`GET /jobs/{id}` 提供状态、进度、失败原因、结果和下载可用性。任务由后台真实执行，不能在请求中伪造成功。查询文档位于 `/api/v2/docs`，前端接口类型由 OpenAPI 生成。

原始观测绑定不可变 `SourceFile`，当前修订通过 `is_current` 选择；插补和预测写 `DerivedValue`，不覆盖原始证据。评价绑定源文件哈希和完整标准快照；模型保存输入矩阵、代码哈希、种子、特征、环境、指标和权重。

## 权限与事务

浏览器 Cookie 为 HttpOnly，CSRF 同时验证令牌和 Origin。修改口令、角色或停用账号会吊销服务端会话。失败登录与越权拒绝独立提交审计，避免业务回滚把记录一起撤销。

管理员与主管可以分派和审核；执法人员按负责人及协作人归属读取、修改核查；研究者没有企业证据访问权。附件和任务下载每次重新检查权限，私有卷不通过静态目录公开。

核查修改携带版本号；旧版本返回 409。任务提交使用目标指纹和 PostgreSQL 事务锁去重，发件箱与任务一起提交；Worker 的会话锁跨越业务事务，进程终止自动释放。通知发送采用幂等键，但外部邮件系统仍可能在网络中断时重复投递。

## 前端规范

深色导航、浅色内容区、蓝绿色主色；污染等级与业务状态采用独立语义颜色和文字。全局城市、日期与页面筛选写入 URL，表格可横向滚动。桌面面向分析，平板支持任务录入与证据上传。

所有生产图表调用真实接口。加载、空结果、403、请求失败、数据延迟和模型不可用分别呈现；图表提供文字摘要、缩放、图例和明细联动。未保存核查事实使用路由阻止与 beforeunload 提示。
