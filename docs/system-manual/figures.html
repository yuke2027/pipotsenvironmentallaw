授权确认文件校验
provider 匹配 · 签署人 · 证据哈希 · 有效期
判定结果
ok — 确认有效且在有效期内放行采集
blocked — 已过期 / 记录无效 / 数据源不匹配所有环境拒绝，任务记录错误原因
unconfigured — 未配置授权生产环境拒绝；非生产允许（联调用）
授权文件要点（JSON · 可审计）
provider：Quotsoft / 官方接口
scope：trial_operation（须 valid_until）或 continuous_business_use
confirmed_by / confirmed_at / reference：签署留痕
evidence_sha256：授权佐证文件哈希
valid_until：试运行授权截止（到期全环境阻断）
ESP_SOURCE_LICENSE_CONFIRMED 为部署总开关；门禁在适配器 collect() 内执行，调度、手工任务、CLI 三条入口同一规则。
